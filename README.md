# Skill Up Galaxy - Student Skill Sharing Platform

A web application that enables students to share skills, exchange knowledge, track learning progress, and collaborate through AI-powered features.

## Features ✨

- **Skill Exchange Marketplace**: Offer and request academic skills
- **Smart Notes System**: Create, organize, and summarize notes with PDF support
- **Lecture Support**: Share and summarize lecture materials
- **Progress Tracking**: Visual learning analytics with interactive charts
- **AI Study Buddy**: 
  - Note summarization
  - Video lecture summarization
  - Interactive Q&A assistance
- **Responsive Design**: Works on all devices

## Technologies Used 🛠️

- **Frontend**: HTML5, CSS3, JavaScript
- **Libraries**: 
  - Chart.js for data visualization
  - Animate.css for animations
  - PDF-lib for PDF handling (simulated in demo)
- **Design**: Custom UI with responsive layouts
